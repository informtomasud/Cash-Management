গুগল শিট ক্লাউড ডাটাবেজ ব্যাকআপ

লাইফটাইম ফ্রি ও শতভাগ নিরাপদ গুগল ড্রাইভ স্টোরেজ

গুগল শিট সংযোগ করার সহজ ৪টি ধাপ:

  1. আপনার গুগল ড্রাইভে একটি নতুন Google Sheet তৈরি করুন।
  2. গুগল শিটের মেনু থেকে Extensions > Apps Script-এ যান।
  3. নিচের "Apps Script কোড কপি করুন" বাটনে চাপ দিয়ে কোডটি সেখানে পেস্ট করুন।
  4. Deploy > New deployment > Web app নির্বাচন করুন (Who has access: Anyone সিলেক্ট করে Deploy চাপুন)।
  5. প্রাপ্ত Web App URL টি নিচের বক্সে পেস্ট করে সেভ করুন।
